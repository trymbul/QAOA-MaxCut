# QAOA for Max-Cut

## Overview

This project investigates the Quantum Approximate Optimization Algorithm (QAOA)
applied to the Max-Cut problem.

The main goal is to implement QAOA from scratch and investigate how its performance depends on the circuit depth (p) and the size of the input graph. The QAOA results are compared with classical methods to evaluate solution quality and computational cost.

The experiments use cycle graphs of different sizes. For small graphs, an exact brute-force solver is used to determine the optimal Max-Cut value. A classical local-search heuristic is also used as a baseline for comparison.

The project focuses on:

    implementing QAOA and its parameter optimization,
    investigating the effect of circuit depth (p),
    studying the effect of problem size,
    comparing QAOA with classical approaches, and
    visualizing measurement probabilities and optimization results.

### `src/`

Contains the main implementations used in the project.

* `qaoa.py` contains the QAOA state preparation and expectation-value calculations.
* `measurement.py` contains functions related to measuring and representing quantum states.
* `graphs.py` contains graph generators used in the experiments.
* `classical.py` contains the exact brute-force Max-Cut solver.
* `classical_heuristic.py` contains the classical local-search heuristic used as a baseline.

### `experiments/`

Contains scripts used to run experiments and generate results.

* `parameter_optimization.py` performs classical optimization of the QAOA parameters.
* `parameter_scan.py` performs grid-based parameter scans.
* `plot_comparisons.py` generates plots comparing the experimental results.
* `classical_baseline.py` runs the classical baseline algorithms and stores their results.

### `figures/`

Contains plots generated by the experiments, including parameter landscapes, measurement probabilities, and comparisons between different QAOA depths and graph sizes.

### `results/`

Contains the numerical results produced by the experiments. These files are used to reproduce and analyze the results without having to rerun the computationally expensive simulations.




## Project goals

- Implement a basic quantum state-vector simulator
- Implement common quantum gates
- Formulate Max-Cut as a cost Hamiltonian
- Implement QAOA
- Optimize the QAOA parameters
- Compare QAOA with classical brute-force optimization
